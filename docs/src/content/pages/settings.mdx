This page goes through the Settings screen row by row, in the order the app shows them. Each row has what it does, the choices it offers and the value a fresh install starts with. Find the category you opened, then the row.

Open Settings with the **Settings** button on the dock. Settings slides up as a sheet over the dashboard. Swipe it down, tap outside it or tap the back arrow to close it.

- **Layout.** On a wide screen the categories form a column beside the rows. On a narrow screen Settings shows the list of categories first, and a tap opens one, with a back arrow to return.
- **Choices.** A row with up to three choices shows them as buttons. A row with more choices shows the current choice and opens a list when you tap it. The exceptions are **Display size**, a slider with five steps, and **Accent color**, a row of swatches. Switches, sliders and buttons apply at once; only the dialogs that take typed text have a **Save** button.
- **Reset.** Every category except System has a **Reset this section** icon in its header. It restores that category's rows to the values on this page, after asking. It keeps the keys and addresses you entered, the **Status icons** switch (the dock has its own **Reset dock**) and the video file you picked. [System](#system) describes the full reset.
- **Nightly builds.** Rows and categories marked "nightly builds only" exist only in the nightly channel. The [install guide](/install/) explains the two channels.

## Appearance

### Theme and accent

| Setting | What it does | Choices | Default |
| --- | --- | --- | --- |
| **Theme** | Sets the light or dark look of the app. **Auto** follows the device's own light or dark setting. | Auto, Light, Dark | Auto |
| **Accent color** | Sets the accent color of the whole app. **Dynamic** keeps the colors Android takes from your wallpaper (Material You). Every other swatch uses a fixed color. | Dynamic, Blue, Teal, Green, Amber, Orange, Red, Violet, Pink | Dynamic |

### Map color

These rows set the colors of the map. [Live map](/features/live-map/) describes the schemes.

| Setting | What it does | Choices | Default |
| --- | --- | --- | --- |
| **Match app theme** | Gives the map the light or dark look of the app's theme. Turn it off to choose the map's look on its own. | On or off | On |
| **Map style** | Sets the map to light or dark on its own. The row is shown only while **Match app theme** is off. Turning that switch off starts from the look the app has at that moment. | Light, Dark | Shown only after **Match app theme** is turned off |
| **Light scheme** | Sets the color scheme of the map in light mode. The row is shown only with the OpenStreetMap map provider, and not while **Map style** is Dark. | Standard, Accent (app color), Positron, Bright, Liberty, Custom style URL | Standard |
| **Dark scheme** | Sets the color scheme of the map in dark mode. The row is shown only with the OpenStreetMap map provider, and not while **Map style** is Light. | Standard, Accent (app color), Dark Matter, Dark, Fiord, Custom style URL | Standard |
| **Style URL** | The address of a hosted MapLibre style, which the **Custom style URL** scheme loads. The address must start with `https://` and may carry a provider key. The row shows only the host, never the full address. The map shows that style's own credits. If the style cannot be loaded, the map shows a notice; **Clear** returns to the Standard scheme. Without an address, the Standard scheme shows. The row is shown only while a scheme row you can see is set to **Custom style URL**. | An address, with **Save** and **Clear** | Not set |

### Glass

The glass settings shape the floating cards over the map.

| Setting | What it does | Choices | Default |
| --- | --- | --- | --- |
| **Blur radius** | Sets how strongly a card blurs the map behind it. | 0 to 40 dp | 16 dp |
| **Glass opacity** | Sets how solid a card is. 0 % is clear glass and 100 % is an opaque card. | 0 to 100 % | 50 % |
| **Panel border** | Draws an outline around each card. | On or off | Off |
| **Panel shadow** | Draws a soft shadow under each card. | On or off | On |
| **Shadow intensity** | Sets how strong the shadow is. The row is shown only while **Panel shadow** is on. | 0 to 100 % | 40 % |
| **Shadow size** | Sets how far the shadow spreads. The row is shown only while **Panel shadow** is on. | 0 to 24 dp | 8 dp |

### Fonts

| Setting | What it does | Choices | Default |
| --- | --- | --- | --- |
| **Latin font** | Sets the typeface for letters and numbers. Opens the font picker. | System default, a Google Fonts family, or a font installed on the device | System default |
| **CJK fallback** | Sets the typeface for Chinese, Japanese and Korean characters, and for any character the Latin font does not have. Opens the font picker. | System default, a Google Fonts family, or a font installed on the device | System default |
| **Font size** | Sets the base text size. Every other text size scales from it. | 14 to 20 sp | 16 sp |
| **Font weight** | Makes all text lighter or heavier. The row shows the weight of regular text as a number. Each step changes the weights by 100. | Five steps, from 200 to 600 for regular text | 400 |
| **Letter spacing** | Sets the space between letters. | -0.02 to 0.10 em | 0.00 em |

The font picker lists **System default**, the fonts installed on the device and the Google Fonts families, with a search field and a **Most popular first** order. Families that cover Chinese, Japanese or Korean are marked "CJK". Choosing a Google Fonts family downloads its file once and keeps it on the device. Opening the picker asks Google Fonts for the current list of families, and the app saves the list on the device so it shows without a connection. [Privacy and data](/features/privacy/) says what each request carries.

| Setting | What it does | Choices | Default |

| **Map type** | Sets the kind of map Google draws. | Roadmap, Satellite, Hybrid, Terrain | Roadmap |
| **Traffic overlay** | Draws live traffic on the Google map. | On or off | Off |
| **Google Maps API key** | Your own Google Maps Platform key. The dialog says what the key needs: a Google Cloud project with billing and the Maps JavaScript API enabled, and a referrer restriction that allows `https://appassets.androidplatform.net/*`. | **Map ID (optional)** | A Map ID from your Google Cloud console, for cloud styling and advanced markers. The **Rendering** choice, not the Map ID, picks raster or vector; only under **Automatic** can the Map ID's cloud configuration decide. | An ID, with **Save** and **Clear** | Not set |
| **Google Maps Platform terms** | Opens Google's own terms in a browser. They cover the key you use, including the restrictions on in-vehicle use. | None | Not applicable |

### Camera

| Setting | What it does | Choices | Default |
| --- | --- | --- | --- |
| **Map tilt** | Sets how far the camera tilts from straight down toward the horizon. | 0 to 60° | 55° |
| **Map zoom** | Sets the zoom level. The zoom buttons on the map change the same value. | 12 to 19 | 16 |

### Saved map regions (nightly builds only)

The **Saved map regions** row appears only in nightly builds, and only with the OpenStreetMap provider. It opens a screen that saves regions of the map on the device. The map does not draw saved regions yet.

- **Add region** lists the regions Geofabrik publishes and suggests one for the current location. A region shows its download size before you save it. One region downloads at a time.
- An interrupted download pauses. **Resume** continues it, and **Cancel** discards the part already downloaded.
- **Storage limit** caps the total size of the saved regions. Lowering it deletes nothing. The choices are No limit, 1, 2, 5, 10, 20 and 50 GB, and the default is No limit.
- Each saved region shows its size and the date of its data. **Delete** removes it after asking.

### Routing data (nightly builds only)

The **Routing data** row appears only in nightly builds, and only with the OpenStreetMap provider. Its summary reads "None on this device yet" or the number of areas and their total size. It opens a screen that lists each 5° × 5° area with its size and the date of its last check. Each area has **Delete**, and **Delete all routing data** removes every area. Both ask first. A route that needs a deleted area downloads it again, after asking. [Live map](/features/live-map/) describes how routes use the data.

| Setting | What it does | Choices | Default |

| **Track recording** | Records position, speed, bearing and altitude while you drive, for the trip replay. The history stays on the device. | On or off | On |
| **Keep track history** | Sets how long recorded points are kept before they are pruned. | 30 days, 90 days, 1 year, Until I delete it | 90 days |
| **Export track history** | Saves the recorded history as a GPX file. Android's file picker lets you choose where it goes. The row then reports how many points it exported, or that the export failed and nothing was written. | None | Not applicable |
| **Delete track history** | Removes every recorded point from the device, after asking. This cannot be undone. | None | Not applicable |

## Updates

[Install](/install/) walks through updating, including what happens while the vehicle moves. Opening this category starts nothing by itself. While an update is on offer, the category carries a dot in the list of categories. Some rows appear only when they apply.

| Row | What it shows or does | Shown |
| --- | --- | --- |
| **Updated to …** | Confirms that the new version is installed and running. | After an update, until you leave **Updates** |
| **Installed version** | The running version and its channel, Stable channel or Nightly channel. | Always |
| **Available version** | The newer version and its download size, marked "Skipped" if you skipped it, or "Up to date". | After a check has found a newer version or found none |
| **Check for updates** | Checks the channel's release feed now. The summary says when the last check ran, that none has run, or why the last one failed. | Always; a tap works while no check or update is under way |
| **Update to …** | Downloads the update and checks it, then Android asks you to confirm the install. The row changes with the stage: it shows the download size, then the progress, then the verified update ready to install. | While an update is on offer |
| **Show the install dialog again** | Shows Android's install confirmation once more, after one was closed without an answer or held back while the vehicle moved. | After an install was handed to Android |
| **Retry** | Tries a failed update again and shows its size first. | After a failure that still has an update on offer |
| **Discard download** | Deletes the downloaded file. The update stays on offer. | While a verified download waits |
| **Skip this version** | Stops the reminders about this version. A newer version is offered again. | While an update is on offer and not yet skipped, but not while it downloads or installs |
| **Check automatically** | Looks for a new version once a day. Nothing downloads until you ask. On by default. | Not shown in a build that never checks |
| **Open release page** | Opens the channel's release page in a browser, to download the update by hand. | Always |

### Reset to defaults

The reset dialog, **Reset settings**, is a checklist. It has one checkbox per category that has settings of its own, labeled with the category's name, and every box starts ticked. Below them is **Keys and addresses you entered**, which starts unticked. It covers the Google Maps key, the Map ID, the custom style URL and the tile host.

- **Reset** restores the ticked categories to the defaults on this page. It stays disabled while nothing is ticked.
- Ticking **Keys and addresses you entered** also deletes those values and puts the map provider back to OpenStreetMap.
- With every category ticked, the reset also covers a category that this build does not list.
- The reset leaves alone the dock and its status icons, the pinned and hidden apps, saved places and the track history. It also keeps the video file you picked.

The **Reset this section** icon in a category's header does the same for that one category, after asking.
