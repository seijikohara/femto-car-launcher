## Requirements

- Android 13 (API level 33) or later.
- Permission to install apps from outside an app store on the device
  ("Install unknown apps"), or `adb` access to it.

## Download a build

Femto Car Launcher publishes two channels as release-signed APKs, both
built from the repository by continuous integration. There is no
app-store listing at present, and sideloading is the supported
installation path for both.

- **Stable** — a dated release that only changes when a build is
  judged ready, published as a
  [GitHub release](https://github.com/seijikohara/femto-car-launcher/releases/latest).
  Download `femto-car-launcher-v<version>.apk`.
- **Nightly** — the newest test build, which changes often and may
  break, published as a rolling
  [`nightly`](https://github.com/seijikohara/femto-car-launcher/releases/tag/nightly)
  prerelease that replaces itself on every push that changes the APK.
  Download `femto-car-launcher-nightly.apk`. Its launcher icon carries
  an "N" badge and its app name reads "Femto Nightly", so it never gets
  mixed up with stable.

The two channels use different application ids and install side by
side, so trying a nightly build never means uninstalling stable, and
switching back is just as easy.

1. Download the APK for the channel you want from its release page.
2. Install it by sideloading on the device, or from a computer:

    ```bash
    adb install -r <file>.apk
    ```

3. Open the app. It asks for the permissions its panels need —
   location for the map and the speed readout, calendar for the
   agenda, notification access for now playing. A permission you deny
   renders a reduced card, never an error screen.

The in-app diagnostics report (**Settings → System → Diagnostics**)
names the installed build by its version name, which is what a bug
report should quote.

## Make it the home screen

- **Built-in Android head units and phones:** open Android's default-apps
  settings and choose Femto Car Launcher (or Femto Nightly, on the
  nightly channel) as the home app. On a phone this step is optional —
  the launcher also runs as a regular app.
- **Aftermarket AI boxes:** most boxes lock the default-launcher slot. Use
  the box's own "boot-up app" or auto-start setting to launch Femto Car
  Launcher (or Femto Nightly) when the box starts.

## Optional: Google Maps provider

To enable the optional paid map provider under **Settings → Map**, enter a
personal Google Maps Platform API key with the Maps JavaScript API enabled
and an HTTP-referrer restriction allowing
`https://appassets.androidplatform.net/*`. An optional Map ID (created in
the Google Cloud console) renders a vector map with heading-up rotation,
tilt and 3D; a blank Map ID renders a flat north-up raster map. Usage bills
your own Google Cloud account.

## Build from source

A Java Development Kit (JDK) 21 and an Android 13+ device or emulator are
the only prerequisites; the Gradle build provisions Node.js and pnpm on
demand for the bundled map page.

```bash
git clone https://github.com/seijikohara/femto-car-launcher.git
cd femto-car-launcher
./gradlew assembleStableDebug   # debug APK at app/build/outputs/apk/stable/debug/
./gradlew test lint             # unit tests and Android Lint
```
